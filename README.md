# REGAL — One Place. Everything You Need.

REGAL is a modern all-in-one utility website that provides various tools in one place for daily needs, study, multimedia, coding, finance, and other digital needs.

## Features

- 🛠️ Everyday utilities (Calculator, QR Generator, Password Generator, etc.)
- 📚 Study tools (Pomodoro, Notes, To-Do, Quiz)
- 🎵 Media tools (Audio Player, Playlist, Visualizer)
- 💻 Coding tools (Playground, JSON Formatter, Markdown Preview)
- 💰 Finance tools (Savings Calculator, Budget, Split Bill)
- 🧠 Random tools (Number Generator, Name Picker, Wheel Spinner)
- 🔍 Global search with Ctrl+K
- 🌗 Dark / Light mode
- ⭐ Favorites & Recently Used
- 📱 Fully responsive

## Tech Stack

- Next.js 14
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React Icons
- LocalStorage
